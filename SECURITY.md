## Reporting a Vulnerability


Reporting a Vulnerability can be completed by individual navigating to _Issues_ Tab on GitHub Page for PA-WeeklyWorkSearchTracker.
- Search archive/backlog for known security issue before submission
    - If determined to already exist:
        - Create additional comment on the existing referenced issue. Including necessary fix/recommendation
    - If determined to be a new observation:
        - Create new issue with tag #unconfirmedIssue to help team prioritize and confirm any linked existing records.
